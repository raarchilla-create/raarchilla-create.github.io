# Rodrigo Archilla — Hospitality Technology Consultant

Bilingual personal website, articles and interactive hospitality tools.

## Live site
https://raarchilla-create.github.io/

## Features
- English and Spanish switcher
- Light and dark themes
- Three bilingual long-form articles
- Searchable article cards and share action
- Three interactive, illustrative calculators (labor cost, food cost, first-year ROI)
- Anonymised case studies and career timeline
- Basic SEO, sitemap, robots.txt, social preview asset

## Publishing
GitHub Pages from main / (root). All content runs as static HTML, CSS and JavaScript. No build step.

## Limitations
Comments, subscriptions and AI assistant are not connected. Calculators are illustrative and store no input on a server. Article content is stored in the index.html contentData JSON script block; edit both language variants when publishing new articles. Article views are hash-based rather than standalone crawlable pages. The social.svg preview may not render in all social networks; a PNG social image is preferable.
